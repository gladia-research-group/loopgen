# LoopGen: Training-Free Loopable Music Generation

## Installation
To use this repository you need python 3.11. The required libraries are listed in `requirements.txt`, therefore installing them is as easy as running:
```
pip install -r requirements.txt
```

## Usage
Examples for using our code can be found in `pipelines.py`, with its functions, you can reproduce all of the setups described in the paper.
